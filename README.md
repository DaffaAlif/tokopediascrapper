# Tokopedia Review Scraper

A simple scraper built to extract customer reviews from Tokopedia product pages. This project helps gather product reviews for analysis, sentiment evaluation, or other purposes. It uses web scraping techniques to collect the data and format it for further use.

## Features
- Scrapes customer reviews from Tokopedia product pages.
- Retrieves review details like rating, review text, and reviewer information.
- Exports data into CSV or JSON format for easy processing.
- Handles pagination to scrape multiple pages of reviews.

## Requirements

Before running the scraper, ensure you have the following installed:

- [Node.js](https://nodejs.org/) (v14.x or later)
- [Puppeteer](https://github.com/puppeteer/puppeteer) or any web scraping library of your choice

To install the required dependencies, run:

npm install puppeteer
